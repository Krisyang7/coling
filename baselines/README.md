# Completed reference results

`comparison_summary.json` contains the audited student, sampled-token OPD, and representation-only OPRD-Bridge aggregate results used in the draft.

`teacher/results/` and `oprd_then_opd/results/` contain the original aggregate evaluator JSON files for the teacher reference and completed sequential OPRD-Bridge → OPD run. Machine-local paths in those JSON files were replaced with public model or artifact identifiers; metrics and evaluation settings are unchanged.

Rollout-level generations are intentionally excluded because they are large and may contain dataset content. Model weights and optimizer checkpoints are also excluded.
